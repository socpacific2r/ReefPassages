## PAGES & FILES

### HTML & JAVA files

1. `index.html`: all the website revolves around this unique page (except for mobile phones). Additional pages are from other websites (mainly [socpacific.link](https://socpacific.link/)) or are automatically generated by the browser.
    `index.html` is segmented into 4 sections: `id="webmap"`, `id="contact"`, `id="credits"`, `id="footer"`. The main one is the webmap section gathering introduction and detailed texts and the webmap. In this section, the code is segmented by comments. 

2. `html/mobile_map.html`: this page is only meant for mobile functions. It only displays a full-screen webmap with a specific id that allows `javascript/map.js` to set differentiated values to make the webmap more user-friendly on mobile phones.
   
3. `javascript/map.js`: mainly defines the webmap, its layers and features (pop-up panels, layerswitcher, etc.). Also gathers the code for a few quality of life upgrades such as the location selector or the full-screen view. 

### CSS files

4. `css/css.css` : main css aplying for global page style. (nav, credits and footer)
5. `css/contact.css` : CSS with specific values for the contact form down the page. (section id = `"contact"`)
6. `css/map.css` : CSS with specific values for the webmap style and its features (fullscreen, information and media panels). (section is = `"webmap"`)
7. `css/mobile_map.css` : the exact same as `map.css` with very specific values for mobile phones features.

## HOW TO EDIT...

> This section covers the features, sections of code, or attributes that will most likely be modified or enriched by the contributions. 

---

### Add a new image to a passage's media panel
Save the image as a `.jpg` named by the passage's ID (e.g. "`230.jpg`") in `media/webmap/pictures`.

> Note : the code only support 1 image file per passage and the file must be `.jpg` (the code can be tweaked to support other type of image files).

---

### Enrich a passage's description
Open the corresponding `.geojson` file in QGIS or any other GIS software, head to the attribute table of the layer and edit the "DESCRIPTION" field.

> Note : a description written in html is properly read by the script. Therefore, links and images can be added like so : 

> **Link** : "click this `<a href="https://socpacific.link/" target="_blank">link</a>`."

> **Images** or **other files** : `<img src="../../media/webmap/pictures/medianame.ext"/>` or `<a href="path/or/url">click here</a>`.

>/!\ Please, ensure that the whole description is inbetween `<p></p>` or `<a></a>` tags to avoid any bug in display.
